# Marketing consent (show the community, with permission)

Noah wants to post the community on TikTok/Instagram but needs clear consent. Users choose how they can be shown.

## Three options (simple)

1. **Private** (default)  
   Don't use my profile or content for marketing. Only visible in app.

2. **Anonymized** (middle)  
   You can use my tagline, quotes, or progress in posts, but **don't show my name or photo**. E.g. "a souper said this…" with no face/name, or anonymized level/stats. Good for "look at the community" without exposing identity.

3. **Public**  
   You can feature me: name, face, tagline, on TikTok/Instagram. Full attribution.

Default is **private** so everyone has to opt in. Copy in the app should make each option clear so users know what they're choosing.

## Later: granular toggles (optional)

If we need finer control later we could add: share_tagline, share_face, share_name, share_voice (e.g. use a voice clip in a reel). For now the three-tier (private / anonymized / public) covers the main cases and keeps consent simple.

## Voice memos

Voice is trickier for "anonymized" (voice can be identifying). For **anonymized** we treat it as: no name, no face; tagline/quotes/progress ok in text or as "a souper said…". Using actual voice clips in marketing would need explicit opt-in (e.g. only from **public** users, or a separate "ok to use my voice in a reel" later).
