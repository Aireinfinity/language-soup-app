# Marketing Assets & Design References

> One place to find photos, logos, and design references for social, store, and marketing. Design *rules* (colors, vibe) live in [CONTEXT.md](../CONTEXT.md) → "Design Vibe."

---

## 📁 Where everything lives

**Folder:** `code/dashboard/assets/marketing/`

Full structure and notes are in **[assets/marketing/README.md](../assets/marketing/README.md)**. Quick reference:

| Folder | Use for |
|--------|---------|
| **icons** | App icon, adaptive icon, favicon, splash, notification icon, bowl icon |
| **logos** | ls-logo-text, play-store feature graphic, design logos |
| **avatars** | All 7 soup avatars (chicken, tomato, bathtub, water, cereal, acai, salad) — for social or in-app |
| **concepts** | Feature graphics, store graphics, banner concepts |
| **branding** | Logo variations, challenge previews, sketchy icons |
| **whats-new** | In-app "what's new" screens (quests, voice feedback, ingredients, etc.) |
| **screenshots** | App screenshots for store listings and social |
| **design/** | InDesign assets, media assets, wrapped graphic, specimens |
| **website** | Hero image, journal covers, website logos |

When you create new Instagram/social graphics, save them in **assets/marketing/social/** (or add a subfolder there).

---

## 🎨 Design rules (quick ref)

For colors, typography, and vibe when making new graphics, see **CONTEXT.md** → section **"Design Vibe (The Language Soup Aesthetic)"**:

- **Background:** Cream `#FDF5E6`
- **Colors:** Turquoise `#00ADEF`, Pink `#EC008B`
- **Vibe:** 2016 Pop / Disco / Pinterest / BeReal. Vibrant, authentic, punchy. No corporate minimalism.
