# Language Soup: User feedback & interviews

**All user feedback lives here** — interviews, support tickets, in-app feedback, whatever. One row per person per touchpoint so we can see how many people we're talking to. When you get new feedback or see something in the support center, add a row here (or paste name + issue and we'll add it). *Previously USER_FEEDBACK.md pointed here; that file is removed.*

### User tiers (who was there when)

Keep track of who showed up at which stage so we can remember and reward them (e.g. merch, early perks, shoutouts). Tiers:

1. **First on the app** — Earliest users; believed in it from the start.
2. **Power users** — People who use the app a lot and shape how it feels (see POWER in the table).
3. **Voluntary app beta testers** — People who opted in to test, report bugs, and give feedback (e.g. app testers group).
4. **Public / everyone** — Once we go broad.

*Note: We won't forget them. Want to do something tangible (merch, exclusive access, or a thank-you) for early supporters when we can.*

### Product learnings (synthesis)

- **Journey (Babka):** Whole path from discovery to first voice memo matters; we're auditing it.
- **Native speakers:** Need an incentive so they show up and correct; users (e.g. Babka, Karen, Jon L) have asked for this.
- **Beginners (Aidan):** Product must work for true beginners (e.g. 8h into a language); use Aidan as persona. Complete beginners must be able to participate.
- **Community feel:** Credit/tag users when we ship features they influenced; app should feel alive ("language social media," "community on your phone").
- **Feature voting:** Let users see and vote on what we're building (Community tab); builds ownership and gives priority signal.
- **Creator economy (later):** Language creators' videos, get them paid, help learners — future bet.
- **Activation / why people aren't activating:** Voice fear is a major blocker (e.g. Ava — president, scared to send voice memos). Insights: fear of being "on record," judged, or sounding bad; need low-stakes first step, reassurance, and optional text/listen-before-send to build confidence before going full voice.
- **Alpha / sign-up:** Sign-up process feels really long — could be shorter or less up front. Emoji password is creative and gets positive feedback; keep it, trim the rest.
- **Subscription / business model:** AMC (e.g. A-List) is a good subscription business model to reference: clear value (movies per month), habit-forming (going to the movies), community (theatre experience), and simple tier.
- **Duolingo / competitor tone:** Duolingo created a weird language persona that harasses users; it worked for notifications (including the "we won't send any more" style). Learn from what worked, but don't copy or channel that. They're a competitor now but not necessarily in the future. We want our own voice: fun and human, not guilt-trippy or aggressive.
